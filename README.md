# Slide to Markdown

PDF와 PPTX 슬라이드를 **페이지별 Markdown**으로 바꾸는 로컬 웹 앱입니다. 파일을 올리면 페이지마다 제목, 글머리표 목록, 표를 정리하고, 그림 속 글자는 OCR로 읽어 붙입니다. 도식처럼 그림이 중심인 페이지는 따로 표시하고 페이지 이미지도 함께 줍니다.

모든 처리는 이 컴퓨터 안에서 합니다. 서버는 `127.0.0.1`에서만 접속을 받고, OCR도 로컬 CPU에서 돌아갑니다.

`lecture_transcriber`의 강의자료 추출 로직(`tools/pdf_pages.py`, `tools/ocr.py`)에서 텍스트 추출과 그림 페이지 OCR 판정을 가져와, 다른 데이터에 기대지 않는 독립된 도구로 만들었습니다.

## 빠른 시작 (Windows)

`run.bat`을 더블클릭합니다.

1. `.venv`가 없으면 만들고 `requirements.txt`의 패키지를 설치합니다 (처음 한 번).
2. 서버가 준비되면 브라우저에서 `http://127.0.0.1:8766`이 열립니다.
3. 끄려면 서버 창을 닫거나 `Ctrl+C`를 누릅니다.

Python 3.10 이상이 필요합니다. 포트를 바꾸려면 실행 전에 `set SLIDE2MD_PORT=8800`을 입력합니다.

직접 실행하려면:

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m slide2md.server            # --no-browser: 브라우저를 열지 않음
```

OCR 인식 모델은 **처음 OCR할 때 한 번 내려받아** `.venv` 안에 저장합니다. 그 뒤로는 인터넷 없이 동작합니다. `rapidocr`가 없으면 앱은 텍스트만 추출하고, 화면에 "OCR 없음"으로 표시합니다.

## 화면

- **파일 올리기**: 끌어 놓거나 눌러서 고릅니다. 여러 파일을 한 번에 올리면 차례대로 변환합니다. OCR 사용 여부와 OCR 언어(한국어+영어 / 영어)를 고를 수 있습니다.
- **작업**: 올리는 중, 대기, 변환 중(진행률과 현재 단계), 완료, 실패를 보여 줍니다. 변환 중인 작업은 취소할 수 있습니다.
- **결과**: 페이지 구성(텍스트 / 텍스트+OCR / 그림 위주)을 보여 줍니다. 페이지 목록에서 고르면 그 페이지로 이동합니다. **미리보기**와 **Markdown 원문** 탭이 있습니다.
- **받기**
  - `.md 받기`: 문서 하나로 된 Markdown입니다.
  - `ZIP 받기`: 전체 문서, 페이지별 파일(`pages/001.md` …), 그림 위주 페이지 이미지(`images/`)가 들어 있습니다.
  - `복사`: Markdown을 클립보드로 복사합니다.

## 출력 형식

[samples/sample.md](samples/sample.md)는 [samples/sample.pdf](samples/sample.pdf)를 실제로 변환한 결과입니다.

````markdown
# sample

- 원본: sample.pdf (5쪽)
- 페이지 구성: 텍스트 3 · 텍스트 + OCR 1 · 그림 위주 1

## 2쪽 · 이 도구가 하는 일

- 페이지마다 텍스트를 뽑아 Markdown으로 정리합니다
  - 큰 글자는 제목, 글머리표는 목록으로 바꿉니다
...

## 4쪽 · 그림 속 글자

아래는 글자를 그림으로 넣은 예시입니다.

**그림 속 글자 (OCR, 잡음이 있을 수 있음)**

```text
그림 안에 들어 있는 글자입니다
...
```

## 5쪽 · 변환 흐름

> 그림 위주 페이지 — 도형·도식. 원본 이미지는 ZIP으로 받으면 들어 있습니다.
````

- 페이지마다 `## N쪽 · 제목`(PPTX는 `## 슬라이드 N · 제목`)으로 시작합니다.
- 슬라이드 글자가 Markdown 문법으로 해석되지 않도록 `*`, 맨 앞의 `#`, HTML 태그처럼 보이는 `<` 등은 이스케이프합니다.
- OCR 결과는 줄바꿈을 그대로 두려고 `text` 코드 블록에 넣습니다.
- PPTX 발표자 노트는 페이지 끝에 `> **발표자 노트**` 인용으로 붙입니다.

## 변환 방식

### 본문 구조

| | PDF | PPTX |
|---|---|---|
| 제목 | 본문보다 1.2배 이상 큰 글자 (위쪽 40% 안, 또는 1.4배 이상) | 제목 자리표시자 |
| 목록 | `•`, `–`, 기호 글꼴 글머리표 등. 단계는 글머리표의 x 위치로 정함 | 본문 자리표시자 문단과 문단 단계, `buChar`/`buAutoNum` 지정 |
| 표 | 선으로 그린 표 (PyMuPDF `find_tables`) | 표 도형, 차트 데이터 |
| 띄어쓰기 | 글자 사이 간격이 글자 크기의 15%를 넘으면 공백을 넣음 (공백 문자가 빠진 한국어 PDF 대응) | 원문 그대로 |
| 빼는 것 | 쪽 번호, 여러 페이지에 반복되는 머리글·바닥글 | 슬라이드 번호·바닥글·날짜 자리표시자 |

### 그림 페이지 판정

그림 영역(페이지 면적의 2% 이상)을 잘라 OCR한 뒤 페이지마다 출처를 정합니다. 기준값은 `lecture_transcriber`의 기본값과 같고, `slide2md/model.py`의 `Options`에서 바꿀 수 있습니다.

| 출처 | 조건 |
|---|---|
| 텍스트 | PDF 텍스트만으로 충분함 |
| 텍스트 + OCR | 그림 속 글자를 OCR해서 페이지 끝에 붙임 |
| 그림 위주 | 그림이 페이지의 12% 이상을 덮는데 OCR이 빈약함 (80자 미만, 면적 대비 밀도 300 미만, 평균 신뢰도 0.80 미만 중 하나) · 도형 수가 다른 페이지의 중앙값보다 20개 넘게 많음(도식) · 글자가 25자 미만인데 그림이나 도형이 있음 |

그림 위주 페이지는 PDF의 경우 페이지 전체를 PNG로 그립니다. PPTX는 슬라이드를 그림으로 그릴 수 없어서 슬라이드 속 그림 파일을 꺼냅니다. 그림이 작으면 영역 긴 변이 1280px가 되도록 키워서(최대 3배) OCR합니다.

> **OCR 설정 메모**: RapidOCR의 글줄 방향 분류기(0°/180°)는 끕니다. 켜 두면 멀쩡한 한국어 줄을 뒤집힌 것으로 잘못 보고 180° 돌려 읽어, 예컨대 "그림 안에 들어 있는 글자입니다"가 "른 극-를드"처럼 나오는 일이 있었습니다. 슬라이드에는 뒤집힌 글자가 거의 없습니다.

## 보안과 데이터

- 서버는 `127.0.0.1`에만 바인딩합니다. 같은 네트워크의 다른 기기에서는 접속할 수 없고, 주소를 바꾸는 옵션도 일부러 두지 않았습니다.
- `Host` 헤더가 `127.0.0.1`이나 `localhost`가 아니면 거절합니다 (DNS 리바인딩 방지).
- 다른 사이트에서 보낸 POST·DELETE 요청(로컬이 아닌 `Origin`)은 거절합니다.
- 화면은 외부 스크립트, 글꼴, CDN을 쓰지 않습니다 (CSP `default-src 'self'`).
- 올린 원본은 `.work/` 안에만 두고 **변환이 끝나면 지웁니다**. 결과와 이미지는 작업을 지우거나 서버를 다시 켜면 지워집니다. 최근 30개 작업만 남깁니다.
- 업로드 최대 크기는 200MB입니다 (`SLIDE2MD_MAX_MB`로 변경). 확장자와 파일 앞부분(`%PDF-`, ZIP 머리)을 모두 확인합니다.

## 명령줄

웹 화면 없이 같은 변환을 실행할 수 있습니다.

```bash
.venv\Scripts\python -m slide2md 발표.pdf               # → 발표.md (+ 발표_images/)
.venv\Scripts\python -m slide2md 발표.pptx --zip        # → 발표.zip
.venv\Scripts\python -m slide2md 발표.pdf --no-ocr -o out.md
```

## 샘플과 테스트

`samples/`의 파일은 실제 강의자료가 아니라 이 도구를 소개하려고 직접 만든 예시입니다.

```bash
.venv\Scripts\python samples\make_samples.py           # sample.pdf, sample.pptx 다시 만들기
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest
```

| 샘플 페이지 | 확인하는 것 |
|---|---|
| 1 표지 | 큰 제목, 부제 |
| 2 글머리표 | 2단계 목록, 공백 문자 없이 찍은 줄의 띄어쓰기 복원, 쪽 번호 제거 |
| 3 표 | 선으로 그린 3열 표 → Markdown 표 |
| 4 그림 속 글자 | 래스터 그림 속 한국어·영어 OCR |
| 5 도식 | 상자·화살표가 많은 페이지 → 그림 위주 + 페이지 이미지 |

테스트는 대부분 OCR을 가짜 함수로 바꿔 빠르고 결과가 일정합니다. `tests/test_ocr_real.py`만 실제 RapidOCR를 쓰며, 설치돼 있지 않으면 건너뜁니다.

## 한계

- 옛 `.ppt` 형식은 지원하지 않습니다. PowerPoint에서 `.pptx`로 저장한 뒤 올리세요.
- PPTX는 슬라이드 전체 이미지를 만들 수 없습니다. 그림 위주 슬라이드에는 슬라이드 속 그림 파일만 들어갑니다 (EMF/WMF 같은 벡터 그림은 OCR하지 못함).
- PDF 읽는 순서는 PDF 안의 글 상자 순서를 따릅니다. 여러 단으로 된 페이지는 순서가 섞일 수 있습니다.
- 선 없이 정렬만 맞춘 표는 표로 알아보지 못하고 문단으로 나옵니다.
- 암호가 걸린 PDF는 열지 않습니다.
- OCR 결과에는 잡음이 섞일 수 있습니다.

## 폴더 구조

```
slide-to-markdown/
├── run.bat               실행 (가상환경·패키지 준비 → 서버 → 브라우저)
├── requirements.txt      실행 의존성 / requirements-dev.txt 테스트 의존성
├── slide2md/
│   ├── server.py         FastAPI 서버, 작업 대기열, 보안 미들웨어
│   ├── convert.py        형식 판별 → 변환 → ZIP
│   ├── pdf_reader.py     PDF: 띄어쓰기 복원, 제목·목록·표, 그림 영역 OCR, 판정
│   ├── pptx_reader.py    PPTX: 자리표시자·표·차트·노트, 그림 OCR
│   ├── model.py          옵션, 페이지 정보, 출처 판정(judge)
│   ├── markdown.py       Markdown 문서·페이지 만들기
│   ├── text.py           텍스트 정리, 글머리표, Markdown 이스케이프
│   ├── ocr.py            RapidOCR 래퍼
│   ├── __main__.py       명령줄
│   └── static/           화면 (index.html, app.js, style.css)
├── samples/              직접 만든 샘플과 생성 스크립트, 변환 결과 예시
└── tests/
```
