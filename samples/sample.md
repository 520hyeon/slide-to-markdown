# sample

- 원본: sample.pdf (5쪽)
- 페이지 구성: 텍스트 3 · 텍스트 + OCR 1 · 그림 위주 1

## 1쪽 · Slide to Markdown

PDF·PPTX 슬라이드를 페이지별 Markdown으로

직접 만든 샘플 문서

## 2쪽 · 이 도구가 하는 일

- 페이지마다 텍스트를 뽑아 Markdown으로 정리합니다
  - 큰 글자는 제목, 글머리표는 목록으로 바꿉니다
  - 선으로 그린 표는 Markdown 표가 됩니다
- 그림 속 글자는 OCR로 읽습니다
- 결과는 .md 파일이나 페이지별 파일이 든 ZIP으로 받습니다

공백 문자가 빠진 PDF도 띄어쓰기를 복원합니다

## 3쪽 · 지원 형식

| 형식 | 본문 텍스트 | 그림 처리 |
| --- | --- | --- |
| PDF | 텍스트 레이어 | 그림 영역을 잘라 OCR |
| PPTX | 텍스트 상자·표·노트 | 슬라이드 속 그림 OCR |
| 스캔 PDF | 없음 | 페이지 전체 OCR |

## 4쪽 · 그림 속 글자

아래는 글자를 그림으로 넣은 예시입니다.

**그림 속 글자 (OCR, 잡음이 있을 수 있음)**

```text
그림 안에 들어 있는 글자입니다

Text inside images is read too
읽은 글자는 페이지 끝에 따로 붙습니다
```
